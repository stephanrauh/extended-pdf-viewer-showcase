Drag mode — move & resize without creating artifacts

pdf.js has no dedicated “select” mode: to grab an annotation you must be in its creation tool, where every click on the empty page drops a new, unwanted annotation. This page shows you how to implement a drag mode that suppresses exactly those empty-canvas clicks — existing annotations stay fully draggable and resizable — without any change to the library.

  • Double-click an existing ink/stamp/highlight annotation to activate the editor in drag mode.
  • A second double-click switches to paint, a third back to drag, and so on. The toolbar button does the same step.
  • Committing a freshly drawn annotation drops back to drag automatically — so you never accidentally paint after finishing.
  • Double-clicking a text annotation still edits its text (it is deliberately exempt from the cycle).
