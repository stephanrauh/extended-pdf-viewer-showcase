The PDF viewer always renders the PDF file as a canvas. Usually it generates additional layers on top of the canvas, one HTML div each:

  • Canvas (.canvasWrapper) - the page as you see it. It's the only layer that's always there. When you zoom in, pdf.js adds a second "detail" canvas so the visible part stays sharp, and the wrapper also carries the invisible accessibility markup (the struct tree).
  • Text layer (.textLayer) allows you to mark and copy text. It's also the base of the search engine. You can render faster if you set [textLayer]="false", but if you do, your users can't use the find bar.
  • Annotation layer (.annotationLayer) - links, comment popups, file attachments, and interactive forms. Everything in it comes from the PDF file itself.
  • Annotation editor layer (.annotationEditorLayer) - the highlights, free text, drawings, stamps, and signatures your users add with the editor. They become real PDF annotations when the document is saved.
  • XFA layer (.xfaLayer) - the one almost everybody forgets. Pure XFA forms (Adobe's XML form format) are rendered as HTML into this layer instead of being painted onto the canvas. It shares the topmost slot with the annotation editor layer.

You don't have to think much about these layers most of the time. However, these layers are HTML divs, and you can manipulate them.
