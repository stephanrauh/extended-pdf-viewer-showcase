Starting with version 31.1.0, you can put several <ngx-extended-pdf-viewer> tags on the same page. Each viewer shows its own document and keeps its own page, zoom, search, form fields, annotation editors and print job.

Keyboard shortcuts and printing with window.print() or CTRL+P act on the viewer you've clicked or focused last.

Two things are shared by every viewer on the page:

  • pdfDefaultOptions apply to every viewer.
  • All viewers share one theme. A dark viewer next to a light viewer isn't supported.

For the time being, this works with the bleeding-edge version only. With the stable version, you still need the iFrame work-around - select "stable" in the version selector at the top of the page to see it.

With the stable version, you need to put each PDF viewer in an iFrame to display multiple PDF files on the same page.

The bleeding-edge version already allows several <ngx-extended-pdf-viewer> tags on the same page, without an iFrame. Select "bleeding edge" in the version selector at the top of the page to see it.

Note on the demo: since activating server-side rendering, the embedded PDF viewers initially show the wrong content. That won't happen on your machine unless you activate SSR, and I hope to fix it soon.

The demo shows a work-around using a common component, the IFrameComponent. The Angular router maps this component to a path, and the iFrame uses this path to display the PDF file.
