NgxExtendedPdfViewerService

API Overview

The NgxExtendedPdfViewerService provides programmatic control over the PDF viewer. This service allows you to interact with the viewer, manipulate pages, control editors, and perform various operations on the PDF document.

Exporting a page: getPageAsCanvas() / getPageAsImage()

Both methods render a page to an off-screen canvas; getPageAsImage() additionally returns it as a PNG data URL. They share the same parameters: 

getPageAsCanvas(
  pageNumber: number,
  scale: { scale?: number; width?: number; height?: number },
  background?: string,
  backgroundColorToReplace?: string,   // default '#FFFFFF'
  annotationMode?: AnnotationMode,     // default AnnotationMode.ENABLE_STORAGE
  cropBox?: PdfPageCropBox,            // optional region, normalized 0..1
  rotation?: 0 | 90 | 180 | 270,       // optional rotation override
): Promise<HTMLCanvasElement | undefined>

cropBox — screenshot a single region

Pass a cropBox (a { x, y, width, height } rectangle in normalized 0..1 coordinates, top-left origin, on the page's un-rotated frame) to return only that part of the page. To screenshot an annotation, read the editor's event.source.normalizedPageRect from the annotationEditorEvent and pass it straight in — see the Editor events demo. Do not use the editor's raw x/y/width/height: they are stored in the rotation the annotation was added at, so they mis-crop rotated annotations.

annotationMode — what shows up

Defaults to AnnotationMode.ENABLE_STORAGE, so the screenshot is WYSIWYG: it includes annotations you just added with the editor (e.g. an image stamp) and current form-field values, not only the annotations already saved into the PDF. Pass AnnotationMode.ENABLE for saved annotations only, or AnnotationMode.DISABLE for none.

rotation — override the page rotation

By default the screenshot follows the rotation the user applied in the viewer. Pass a rotation of 0, 90, 180 or 270 to override it: 0 always yields the page in its authored orientation no matter how the user rotated it on screen, while 90/180/270 force a specific rotation. When you also pass a cropBox, the crop follows the same rotation.
