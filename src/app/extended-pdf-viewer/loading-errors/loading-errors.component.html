When a PDF file fails to load, pdf.js writes the error to the console and leaves the page empty. Your application learns about it from the (pdfLoadingFailed) event, so you can show a message of your own.

Since version 31.0.0-alpha.3, the viewer can also do that for you: [showLoadingErrorMessage]="true" shows an error card on top of the empty page. "More information" reveals the technical details, and "Close" dismisses the card. The card is translated into every language the viewer supports. [loadingErrorMessage] replaces its headline with your own wording.

The card is off by default, because many applications already handle the error themselves. Opening another file hides the card again. Thanks to Julian-B90 for contributing it!
